## Animation

| Token | Value | Usage |
|-------|-------|-------|
| --duration-fast | 150ms | Micro-interactions (hover, focus) |
| --duration-normal | 250ms | State transitions |
| --duration-slow | 400ms | Page transitions, reveals |
| --easing-default | cubic-bezier(0.4, 0, 0.2, 1) | General motion |
| --easing-spring | cubic-bezier(0.34, 1.56, 0.64, 1) | Bouncy entrances |
| --easing-out | cubic-bezier(0, 0, 0.2, 1) | Exit animations |

**Signature Animation:** Resume cards on the dashboard have a subtle paper dog-ear fold on hover — the top-right corner curls back with a warm gold accent peek-through via a ::after pseudo-element with a diagonal gradient. Landing page sections separated by ink-bleed SVG dividers that subtly animate in on scroll.
